# FORGE Athletics Club

A high-energy, responsive fitness club landing page built with React, Vite, Tailwind CSS v4, Lucide icons, and custom responsive CSS.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build` and run code checks with `npm run lint`.

## Features

- Full-screen action hero, training programs, coaches, memberships, and member stories
- Responsive navigation that changes with scroll position
- Keyboard accessible testimonial controls
- Trial sign-up form with validation and confirmation state
- Lazy-loaded photography, scroll reveals, and reduced-motion support

The trial form is a frontend demo. Connect a backend or form service to receive enquiries.
